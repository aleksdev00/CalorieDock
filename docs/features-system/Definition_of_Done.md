# Definition of Done


# Purpose

This document defines the minimum quality requirements that every feature must satisfy before it can be marked as **DONE**.

A feature is considered complete only when every applicable requirement has been fulfilled.


# Documentation

- [ ] Feature documentation is complete.

- [ ] Documentation reflects the final implementation.

- [ ] Technical decisions are documented.

- [ ] Open questions are resolved or documented.


# Frontend

- [ ] UI implemented.

- [ ] Responsive on supported breakpoints.

- [ ] Accessibility requirements satisfied.

- [ ] Loading states implemented.

- [ ] Empty states implemented.

- [ ] Error states implemented.

- [ ] Success feedback implemented.


# Backend

- [ ] Service layer implemented.

- [ ] Business logic implemented.

- [ ] Validation implemented.

- [ ] Error handling implemented.


# Database

- [ ] Migrations created.

- [ ] Indexes reviewed.

- [ ] Foreign keys verified.

- [ ] RLS policies implemented.

- [ ] Constraints validated.


# API

- [ ] API contract completed.

- [ ] Request validation implemented.

- [ ] Response format standardized.

- [ ] Error responses documented.


# Security

- [ ] Authentication verified.

- [ ] Authorization verified.

- [ ] User ownership enforced.

- [ ] Sensitive data protected.

- [ ] No secrets exposed.


# Performance

- [ ] Queries optimized.

- [ ] Caching reviewed.

- [ ] Bundle impact acceptable.

- [ ] No unnecessary re-renders.


# Testing

- [ ] Unit tests completed.

- [ ] Integration tests completed.

- [ ] Manual testing completed.

- [ ] Edge cases tested.


# Code Quality

- [ ] TypeScript passes.

- [ ] ESLint passes.

- [ ] Build succeeds.

- [ ] No duplicated business logic.

- [ ] Coding Standards respected.


# Review

- [ ] Self review completed.

- [ ] AI review completed.

- [ ] CodeRabbit review completed.

- [ ] All review comments resolved.


# Project Updates

- [ ] Feature Registry updated.

- [ ] Project State updated.

- [ ] CURRENT\_CONTEXT updated.

- [ ] CHANGELOG updated (if applicable).


# Final Approval

A feature may be marked as **DONE** only after every applicable checklist item has been completed.
